# milanmk/actions-file-deployer

Fast and customizable deployment with parallel connections and proxy support. Deploy only changed files or do full sync.

Hardened by [Chainguard](https://www.chainguard.dev) from the upstream action at [https://github.com/milanmk/actions-file-deployer](https://github.com/milanmk/actions-file-deployer).
